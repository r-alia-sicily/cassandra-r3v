# Security policy

## Supported release

Cassandra R3v 1.0.0 is the supported public release.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** security-advisory form for issues that could expose data, execute unintended code, corrupt artifacts, or bypass integrity checks. Do not disclose exploitable details in a public issue before a fix is available.

For ordinary defects, numerical questions, or reproducibility problems, use the public issue tracker and attach only non-sensitive diagnostics. Never attach credentials, private paths, restricted datasets, or proprietary research artifacts.

Cassandra processes user-selected archives and writes local artifacts. Run it only on trusted data and review paths before importing or exporting files.
